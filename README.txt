BLOCKCHAIN CERTIFICATE VERIFICATION SYSTEM — BCA PROJECT

FILES
- index.html: complete application (HTML, CSS and JavaScript in one file)
- Project_Report.docx: editable college project report

RUN ON A MOBILE PHONE
1. Open https://replit.com/ in Chrome and create a free account (if required).
2. Create a new HTML/CSS/JS project (or a simple HTML project).
3. Open index.html and replace its contents with the code from the supplied index.html file.
4. Run the project. Open the public web preview in a new browser tab if needed.
5. Use sample details to register a certificate. Copy the generated CERT-... ID.
6. Paste that ID into Verify a certificate and tap Verify certificate.
7. Add another sample certificate to see the linked block numbers and previous hashes.

IMPORTANT
- Use HTTPS preview. SHA-256 uses the browser Web Crypto API, which requires a secure context.
- Data is saved in localStorage in that browser on that device. Clearing browser site data can erase it.
- This is an educational single-browser prototype, not a real decentralized blockchain.
- Do not enter real personal/student information. Use sample data for demonstrations.
- Do not claim that the system has distributed consensus, immutable public storage, login security or production-grade fraud prevention.
