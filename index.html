Blockchain Certificate Verification System

Register, store and verify academic certificates

1. Register a certificate (Admin)

Enter certificate details. A unique certificate ID and SHA-256 block hash will be generated.

2. Verify a certificate

Enter a certificate ID to check whether its saved data and blockchain links are unchanged.

3. Blockchain records

Each block contains certificate data, the previous block's hash and its own hash.

About this demonstration

This project demonstrates a basic hash-linked ledger in one browser using SHA-256 and local storage. It is not a production system: there is no central server, user authentication, digital signature, distributed consensus or protection against someone editing browser storage directly. Use sample data only.
